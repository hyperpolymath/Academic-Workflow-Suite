= Proven Library Integration Guide
:toc: auto

== Overview

This document tracks integration opportunities for the https://github.com/hyperpolymath/proven[proven library] - a formally verified, crashproof library written in Idris2 with 45 modules and 43 language FFI bindings.

The `proven` library provides mathematically verified safety guarantees for common operations that can crash or behave unexpectedly. By integrating these modules, academic-workflow-suite can achieve stronger runtime guarantees for critical operations.

== Module Integration Details

=== SafeCrypto (CRITICAL)

Formally verified cryptographic operations with guaranteed properties.

==== Current Implementation Locations

[source]
----
components/core/src/security.rs:121-165
  └── SHA3 hashing for student ID anonymization
  └── Key derivation for document encryption

components/shared/src/crypto.rs:47-232
  └── AES-256-GCM encryption
  └── Hash verification routines
  └── Constant-time comparison
----

==== Integration Benefits

* *Crash Safety*: Guaranteed no panics on malformed input
* *Timing Attack Prevention*: Verified constant-time operations
* *Memory Safety*: Proven buffer bounds checking
* *Correctness*: Mathematically verified implementations

==== Migration Path

1. Add `proven-rust` FFI crate as dependency
2. Replace `sha3` crate calls with `SafeCrypto.SHA3`
3. Replace `aes-gcm` calls with `SafeCrypto.AES256GCM`
4. Run differential testing against current implementation

== FFI Binding Requirements

=== Rust Bindings

The `proven` library provides `proven-rust` crate with:

* Direct FFI to Idris2 compiled libraries
* Native Rust types with automatic conversion
* `no_std` support for embedded contexts
* Feature flags for selective module inclusion

[source,toml]
----
[dependencies]
proven-rust = { version = "0.1", features = ["crypto", "json", "regex", "path"] }
----

=== ReScript Bindings

The `proven` library provides `proven-js` package:

[source,json]
----
{
  "imports": {
    "proven": "npm:proven-js@^0.1"
  }
}
----

ReScript binding file:

[source,rescript]
----
// src/bindings/Proven.res
module SafeJson = {
  @module("proven") external parse: string => result<Js.Json.t, string> = "SafeJson.parse"
  @module("proven") external stringify: 'a => string = "SafeJson.stringify"
}
----

== Testing Strategy

=== Differential Testing

Run current implementation and `proven` implementation in parallel:

[source,rust]
----
#[cfg(test)]
mod proven_tests {
    #[test]
    fn differential_sha3() {
        let input = b"student_id_A1234567";
        let current = current_sha3(input);
        let proven = SafeCrypto::sha3_512(input);
        assert_eq!(current, proven);
    }
}
----

=== Property-Based Testing

Use QuickCheck to verify behavior matches:

[source,rust]
----
#[quickcheck]
fn prop_json_roundtrip(s: String) -> bool {
    match SafeJson::parse(&s) {
        Ok(json) => SafeJson::stringify(&json).is_ok(),
        Err(_) => true // Invalid JSON gracefully handled
    }
}
----
