== Overview

This document describes the OAuth 2.0 Authorization Code flow implementation for integrating Academic Workflow Suite with Moodle LMS instances, specifically targeting the Open University's VLE (Virtual Learning Environment) based on Moodle.

=== Goals

1. **Secure Authentication**: Use OAuth 2.0 Authorization Code flow with PKCE
2. **Privacy First**: Minimal scope requests, no persistent credential storage
3. **OU Compatibility**: Support OU's specific Moodle configuration
4. **Multi-LMS Ready**: Architecture extensible to Canvas, Blackboard, etc.

=== PKCE (Proof Key for Code Exchange)

PKCE adds security for public clients (CLI, desktop apps):

[source,rust]
----
// Generate code_verifier (43-128 chars, URL-safe)
fn generate_code_verifier() -> String {
    use rand::Rng;
    let bytes: [u8; 32] = rand::thread_rng().gen();
    base64url_encode(&bytes)
}

// Generate code_challenge from code_verifier
fn generate_code_challenge(verifier: &str) -> String {
    use sha2::{Sha256, Digest};
    let hash = Sha256::digest(verifier.as_bytes());
    base64url_encode(&hash)
}
----

== Moodle Configuration

=== Required Moodle Setup

Moodle administrators must:

1. **Enable OAuth 2.0 Services**
   - Site administration > Server > OAuth 2 services
   - Create new service for AWS

2. **Configure OAuth 2.0 Client**
   - Client ID: `aws-edu-marking-assistant`
   - Redirect URI: `http://localhost:31415/callback` (CLI)
   - Redirect URI: `https://aws-edu.org/oauth/callback` (Web)
   - Scopes: See below

3. **Enable Web Services**
   - Site administration > Plugins > Web services > External services
   - Create service with required functions

=== OAuth2 Client

[source,rust]
----
/// OAuth2 client with PKCE support
pub struct OAuth2Client {
    config: OAuth2Config,
    http_client: reqwest::Client,
}

impl OAuth2Client {
    pub fn new(config: OAuth2Config) -> Self {
        Self {
            config,
            http_client: reqwest::Client::new(),
        }
    }

    /// Start OAuth2 flow - returns auth URL and PKCE verifier
    pub fn start_auth_flow(&self) -> (String, String) {
        let code_verifier = generate_code_verifier();
        let code_challenge = generate_code_challenge(&code_verifier);
        let state = generate_state();

        let auth_url = format!(
            "{}?response_type=code&client_id={}&redirect_uri={}&scope={}&state={}&code_challenge={}&code_challenge_method=S256",
            self.config.authorize_endpoint,
            urlencoding::encode(&self.config.client_id),
            urlencoding::encode(&self.config.redirect_uri),
            urlencoding::encode(&self.config.scopes.join(" ")),
            urlencoding::encode(&state),
            urlencoding::encode(&code_challenge),
        );

        (auth_url, code_verifier)
    }

    /// Exchange authorization code for tokens
    pub async fn exchange_code(
        &self,
        code: &str,
        code_verifier: &str,
    ) -> Result<TokenResponse> {
        let params = [
            ("grant_type", "authorization_code"),
            ("code", code),
            ("redirect_uri", &self.config.redirect_uri),
            ("client_id", &self.config.client_id),
            ("code_verifier", code_verifier),
        ];

        let response = self.http_client
            .post(&self.config.token_endpoint)
            .form(&params)
            .send()
            .await?;

        if response.status().is_success() {
            Ok(response.json().await?)
        } else {
            let error: OAuth2Error = response.json().await?;
            Err(LmsError::OAuth2(error))
        }
    }
}
----

== Security Considerations

=== Token Storage

Tokens must be stored securely:

[source,rust]
----
/// Secure token storage using OS keyring
pub struct SecureTokenStore {
    service_name: String,
}

impl SecureTokenStore {
    pub fn new(service_name: &str) -> Self {
        Self {
            service_name: service_name.to_string(),
        }
    }

    /// Store token securely
    pub fn store(&self, key: &str, token: &str) -> Result<()> {
        let entry = keyring::Entry::new(&self.service_name, key)?;
        entry.set_password(token)?;
        Ok(())
    }

    /// Retrieve token
    pub fn retrieve(&self, key: &str) -> Result<Option<String>> {
        let entry = keyring::Entry::new(&self.service_name, key)?;
        match entry.get_password() {
            Ok(password) => Ok(Some(password)),
            Err(keyring::Error::NoEntry) => Ok(None),
            Err(e) => Err(e.into()),
        }
    }

    /// Delete token
    pub fn delete(&self, key: &str) -> Result<()> {
        let entry = keyring::Entry::new(&self.service_name, key)?;
        entry.delete_password()?;
        Ok(())
    }
}
----

=== Privacy Protections

1. **Minimal Scope**: Only request necessary permissions
2. **No Credential Storage**: Use OAuth tokens, never store passwords
3. **Token Encryption**: Encrypt tokens at rest using OS keyring
4. **Automatic Expiry**: Respect token expiration, refresh as needed
5. **Secure Transport**: HTTPS only, TLS 1.3 preferred

=== Student Data Anonymization

All student data is anonymized before processing:

[source,rust]
----
/// Anonymize student ID using SHA3-512
pub fn anonymize_student_id(student_id: &str) -> String {
    use sha3::{Sha3_512, Digest};
    let mut hasher = Sha3_512::new();
    hasher.update(student_id.as_bytes());
    hex::encode(hasher.finalize())
}

/// Submission with anonymized student data
#[derive(Debug, Clone)]

#[derive(Debug, thiserror::Error)]
pub enum LmsError {
    #[error("OAuth2 error: {0}")]
    OAuth2(#[from] OAuth2Error),

    #[error("HTTP error: {0}")]
    Http(#[from] reqwest::Error),

    #[error("API error: {message}")]
    Api { code: String, message: String },

    #[error("Token expired")]
    TokenExpired,

    #[error("Insufficient permissions: {0}")]
    InsufficientPermissions(String),

    #[error("Rate limited, retry after {0} seconds")]
    RateLimited(u64),

    #[error("Network error: {0}")]
